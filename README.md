# Biblioteca de empréstimos

Este repositório é o laboratório do curso e o exemplo do livro *Uma Página de Cada Vez* (https://jckodel.github.io/focus-kit-book/pt/): uma pequena biblioteca empresta exemplares dos seus livros a membros, e cada entrega nasce de uma página em `work/`.
